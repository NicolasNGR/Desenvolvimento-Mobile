# 📱 Desenvolvimento Mobile

Repositório de aplicativos Android desenvolvidos para a disciplina de **Desenvolvimento Mobile — FATEC, Ciclo 4**. Cada aplicativo fica em sua própria pasta e pode ser aberto individualmente no Android Studio.

## Aplicativos

| Pasta | Descrição |
|---|---|
| [`AppLivro`](./AppLivro) | Aplicativo para consulta de livros. |
| [`Cadastroaluno`](./Cadastroaluno) | Cadastro e consulta de informações de alunos. |
| [`Calculadora`](./Calculadora) | Operações matemáticas básicas. |
| [`CalculoIMC`](./CalculoIMC) | Cálculo do Índice de Massa Corporal a partir do peso e da altura. |
| [`CalculoLeiOhm`](./CalculoLeiOhm) | Cálculo de tensão, corrente ou resistência pela Lei de Ohm. |
| [`ConversorTemperatura`](./ConversorTemperatura) | Conversão de temperatura de Celsius para Fahrenheit. |
| [`PerfilFireAuth`](./PerfilFireAuth) | Cadastro, login, redefinição de senha, logout e exclusão de conta com Firebase Authentication. Veja o [README do Perfil FireAuth](./PerfilFireAuth/README.md) para configuração e execução. |

## Tecnologias

Os projetos usam Kotlin e/ou Java, Android Studio, Gradle e interfaces XML ou Jetpack Compose, conforme a atividade. O Perfil FireAuth também utiliza Firebase Authentication.

## Como executar

1. Clone este repositório:
   ```bash
   git clone https://github.com/NicolasNGR/Desenvolvimento-Mobile.git
   ```
2. Abra o Android Studio e selecione **Open**.
3. Escolha a pasta do aplicativo que deseja executar.
4. Aguarde a sincronização do Gradle.
5. Selecione um emulador ou dispositivo Android e clique em **Run**.

Para os passos específicos de configuração do Firebase e testes do Perfil FireAuth, consulte [`PerfilFireAuth/README.md`](./PerfilFireAuth/README.md).
